## Brand Naming

- NEVER use "Muni" as standalone text. Always "Municipal Robotics" in copy.
- For short form, use the logo mark only — no text abbreviation.
- This applies to headers, nav, body copy, meta tags, everywhere.

## Typography

- **Display/headlines**: Space Grotesk (variable, 300-700)
- **Data/labels/buttons**: Berkeley Mono
- Never use Berkeley Mono for headlines. Never use Space Grotesk for data.

## Layout Philosophy

- Think in "cards" — one concept per viewport, figure.ai style
- Show one thing at a time. Don't crowd.
- Each section should have a single clear message + visual.
